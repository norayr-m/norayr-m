THE ONE HARD BET

every node has at most 6 directed inputs every edge goes from a higher rank to a lower rank every node carries a 64-bit LUT — any 6-input Boolean function the rank rule makes the graph acyclic by construction the 6-bound makes a fixed-size node struct — no pointer chasing the LUT makes per-node computation a one-instruction kernel dispatch
The architecture rests on a single constraint: every node has at most six directed inputs, and every edge flows from a higher rank to a lower rank. Those two rules together make the graph strictly acyclic by construction and fix the node struct at thirty-five bytes — a flat integer-by-six neighbours buffer, no dynamic allocation, no pointer chasing. Each node also carries a sixty-four-bit lookup table, so any six-input Boolean function is one instruction in the kernel. Cheap, uniform, GPU-friendly.

THE BFS PRIMITIVE

bfsDepths(from: Int) -> [Int32] length = nodeCount · -1 for unreachable · 0 for the seed DSL: BFS_DEPTHS FROM <seed> MCP: mcp__dagdb__bfs_depths (zero-copy numpy view via UMA) added today as part of the Loom-on-DagDB work runs on the same neighbours buffer as the core kernel — no new allocation
Also shipped today: a breadth-first-search primitive. `bfsDepths` takes a seed node identifier and returns a per-node depth vector — length equal to node count, zero for the seed, negative one for unreachable nodes. Exposed through the DSL as `BFS_DEPTHS FROM` and through the MCP surface for Python consumers, with a zero-copy numpy view via unified memory. This is the primitive the biology plug-in uses for protein-graph certification and the Loom ingest uses for event-ancestry queries.

SNAPSHOT + PERSISTENCE

snapshot body: 35 bytes per node (38 B after u32 rank) no serialisation: memcpy from GPU UMA straight to disk WAL: F_FULLFSYNC every flush backup chain: base + delta chain + compaction + restore JSON / CSV round-trip for human-readable export
Persistence is a direct memory-to-disk path. The snapshot body is thirty-five bytes per node — thirty-eight after today's rank widening — and the whole state memcopies from unified GPU memory straight to a file on disk. No serialisation step. The write-ahead log uses full fsync on every flush; the backup chain supports base snapshots plus delta chains with compaction and restore; JSON and CSV round-trip for human-readable export. Crash recovery has been tested. Integrity has been tested. The eighty-seven-of-eighty-seven figure includes the persistence and recovery paths.
